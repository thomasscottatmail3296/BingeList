# Provider Link Template

Use this pattern when a provider is introduced into a show, movie, documentary, franchise, season or episode note. Keep one provider image in a shared assets location and reference it rather than duplicating the image.

◇ HUMAN-READABLE LINK
[Provider Name](https://example.com)

◇ WITH SHARED LOGO
<span class="provider-link">![provider logo](path/to/provider-logo.png) [Provider Name](https://example.com)</span>

◇ IMAGE RULES
- Maximum provider-logo dimensions: 128×128 pixels.
- Prefer one shared image asset per provider.
- Keep the provider name as text so the link remains understandable if images are disabled.
- Record the image source and retrieval date in the provider/source note.
