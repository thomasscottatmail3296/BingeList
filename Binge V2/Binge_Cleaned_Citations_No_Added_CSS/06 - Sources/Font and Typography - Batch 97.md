# Font & Typography Standard

◇ PURPOSE
This note defines the Binge Vault typography baseline introduced in Batch 97.

◇ PRIMARY LOCAL FONT
- Family: JetBrains Mono Nerd Font
- Bundled assets:
  - `fonts/JetBrainsMonoNerdFont-Bold.ttf`
  - `fonts/JetBrainsMonoNerdFont-BoldItalic.ttf`
  - `fonts/JetBrainsMonoNerdFont-ExtraBold.ttf`
- Use: headings, code, technical labels, terminal-style UI elements and compact metadata.

◇ OFFICIAL SOURCE
- Nerd Fonts release/download site: https://www.nerdfonts.com/font-downloads
- Current Nerd Fonts release reference checked for this build: v3.5.1 (2026-08-21).

◇ SAMSUNG FALLBACK
SamsungOne / Samsung system typefaces are intentionally not redistributed in this vault. Obtain Samsung fonts through Samsung's own supported distribution channels where available.

- Samsung Design System — Font: https://developer.samsung.com/design-system/font
- Samsung One UI typography guidance: https://developer.samsung.com/one-ui/accessibility/layout-and-typo.html

◇ DESIGN RULES
- Body text remains on the Obsidian/system text stack for broad language coverage.
- Technical headings and code use the bundled Nerd Font.
- Provider logos are shared assets, not duplicated per note.
- Provider images are capped at 128×128 pixels.
- Human-readable provider names remain visible beside links; images are supporting visual cues only.
- No proprietary Samsung font files are bundled.

◇ BATCH STATUS
Batch 97 typography and link-formatting baseline: complete.
