# Batch 198 - Duplicate Stem Classification

## Scope
Classified duplicate Markdown stems without deleting files.

## Results
- Markdown files: 3487
- Duplicate stem groups: 478
- Episode-style duplicate groups intentionally retained across separate series: 450
- Non-episode duplicate groups requiring future review: 28

## Rule
Identical episode filenames such as `S01E01.md` are not duplicates when they belong to different shows. No deletion or renaming was performed in this batch.
