# V6 — Recovered Watchlist Reconciliation

This index records the recovered-list integration into **Binge V6 - Codex**. V5 remains the reference baseline and is not modified by this V6 build.

## Integration rules

- Existing V5 notes are preserved unless a new canonical entry was required.
- Franchise requests are represented by explicit parent/franchise notes where appropriate.
- TV series and film adaptations remain separate entries while sharing a franchise/collection relationship.
- Episode metadata is not invented during this merge.
- Ambiguous titles remain identifiable for later source verification rather than being silently reclassified.
