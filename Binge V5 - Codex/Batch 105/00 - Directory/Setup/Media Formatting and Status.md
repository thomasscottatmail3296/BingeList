# Media Formatting and Status

◇ TREE STANDARD
- Universe → Title → Season → Episode
- Season folders use two-digit numbering where practical (`Season 01`, `Season 02`, …).
- Existing note content is preserved; this pass changes location/structure, not factual metadata.

◇ WATCH STATUS — CANONICAL VALUES
1. `Not Watched` — default
2. `Watched`
3. `In Progress of Watching`

The visible checkbox section remains human-readable. The Obsidian-native dropdown enforcement belongs to the companion plugin layer, which can constrain the `status` property to these three values.

◇ VIEWING PLATFORM STANDARD
- Free
- Torrent — Legal and Non-Legal
- Paid
- Australian pricing is stored as `AUD` with billing occurrence when verified.
- Unverified provider availability is explicitly labelled rather than guessed.
