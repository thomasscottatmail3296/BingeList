## ◇ BUILD STATUS

This package contains the redesigned architecture and relationship layer. Episode-level records should only be generated from verified source data; no guessed episode titles or timestamps are inserted.

## ◇ DATA SOURCES

- TV episode metadata: TVmaze public API
- Continuity/franchise cross-checks: Wikipedia
- Images: preferably Wikimedia Commons or source-permitted TVmaze images
- Timestamp data: only release/version-specific sources when available

The TVmaze API documents episode lists, season episodes, specials, alternate lists and episode images, making it suitable for generating the episode layer.
