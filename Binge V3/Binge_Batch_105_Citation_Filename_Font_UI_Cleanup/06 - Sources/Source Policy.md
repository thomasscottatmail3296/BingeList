# ◇ SOURCE POLICY

## Episode metadata

Primary candidate: TVmaze's public API.

TVmaze documents endpoints for complete show episode lists, season episodes, episode metadata, images, alternate episode lists and specials. Its API is therefore suitable for generating the machine-readable skeleton of the vault. 

## Episode titles and continuity

Wikipedia episode-list articles are used as a cross-check, especially where TVmaze's naming or season numbering needs verification.

Example: the current Rick and Morty episode article exposes season-by-season episode tables and also separately lists anime, webisodes and Vindicators 2. 

## Summaries

The vault should contain short original paraphrases rather than copied episode-guide prose. A source can be linked for verification.

## Timestamps

Timestamp lists should only be marked as verified when a source provides them for a matching release/version. Broadcast, streaming, Blu-ray and extended cuts can have different timings.

If no reliable timestamp source exists, the field should say:

`Timestamp data: not verified`

It must not contain invented timestamps.

## Images

Prefer:
1. Wikimedia Commons / freely licensed images
2. TVmaze artwork where its usage terms permit the intended local vault use
3. Official promotional artwork only as a reference link when redistribution rights are unclear

The vault should not silently package copyrighted poster art as if it were public-domain.

## Universe classification

Continuity relationships are treated separately from simple franchise membership. A title can be:
- a spin-off but not a sequel
- an adaptation but not the same continuity
- part of a shared multiverse but a different universe
- a companion/special without being a separate continuity
