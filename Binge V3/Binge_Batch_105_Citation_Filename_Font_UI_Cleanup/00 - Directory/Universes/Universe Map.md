# ◇ UNIVERSE MAP

This is the relationship layer of the vault. A title can belong to a universe without being a direct continuation of the main series.

Relationship labels used throughout the vault:

- `MAIN` — primary series/film line
- `SPIN-OFF` — derived from an existing work
- `SEQUEL` — continues a prior work
- `PREQUEL` — set before a prior work
- `ANIMATED ADAPTATION` — animated retelling/parallel adaptation
- `COMPANION` — supplementary series or format
- `ALTERNATE PERSPECTIVE` — same/related continuity viewed through different characters
- `ALTERNATE UNIVERSE` — distinct continuity
- `REIMAGINING` — a substantially different interpretation
- `BACKDOOR PILOT` — episode/project intended to establish a spin-off
- `INTERNATIONAL ADAPTATION` — local adaptation, not automatically the same continuity
- `RELATED` — connected by production/franchise but not necessarily one continuity
